## 〇、运行环境（先看这一节）

| 项目 | 要求 |
|---|---|
| 系统 | Windows 8.1 / 10 / 11，64 位 |
| 依赖 | 无。不需要 Python、.NET 或 Office；单文件 exe，双击即用，拷到 U 盘也能跑 |
| 浏览器 | 只有「文档：预览转PDF」需要，用系统自带的 Edge 即可；没有 Edge 会自动找 Chrome |
| 磁盘空间 | 程序约 12 MB；下载的资料按实际大小算（视频单个几十到几百 MB） |
| 权限 | 普通用户权限即可，不需要管理员 |
| 网络 | 校园网 / 代理均可（跟随系统代理），需要能访问 `abooks.hep.com.cn` |

关于 Windows 7：Python 3.9 起已不再支持 Win7，本程序编译在 Python 3.12 上，所以 Win7 打不开，
这不是配置问题；32 位系统同样无法运行（发布的是 x64 版本）。

关于只读目录：若在只读目录（如只读 U 盘、受控共享盘）里运行，配置和下载列表会自动改存到
`%LOCALAPPDATA%` 或临时目录，不会因此报错退出。

## 一·补、界面速览（v1.11 重新设计）

整窗自上而下四块，圆角白卡片铺在浅蓝灰底上，从"工具界面"改成一张"资料目录"的样子：
留白多一些，边框细一些，颜色只用在需要看的地方。

```text
┌ 顶栏     Φ 标记 + 名称 + 一句话说明；右上角「登录 / 令牌」「刷新数据」
├ 筛选卡   年份 / 类别 / 奖项 / 资料 四个下拉 + 搜索框；最右「重置筛选」
├ 目录卡   标题「作品目录」，右侧一行小字：筛选 x/y · 可下载 n · 仅预览 m
│          下面是表格，表头淡蓝，行高放宽，选中行浅蓝底
└ 操作卡   保存路径 + 浏览 / 打开目录
           蓝色主按钮「加入下载列表」、「下载列表 (N)」、下载选中 /
           下载当前列表、导出清单、右侧「停止」
           三个胶囊开关：跳过已存在 / 按年份奖项分文件夹 / 预览转PDF
           最底部一条细进度条 + 一行状态文字
```

### 用色

主色淡蓝 `#4A85D8`，只出现在主按钮、勾选后的行、选中的开关与进度条上；其余全是白 / 浅灰蓝。
红、绿只用于"失败 / 完成"这类必须提醒的状态。

### 勾选

行首 ☐ 点一下变 ☑，整行文字转蓝；表头「选」可整批勾选 / 取消。右下角会显示
「已勾 N 项，待下载 M 项」。

### 按钮形态

圆角药丸：实心蓝＝主操作，浅蓝＝和下载列表相关，描边＝次要操作，纯文字＝轻量操作；
「停止」用红色描边，且只在真正下载时才可点。

### 窗口尺寸

默认 1280×864（按屏幕大小自适应），最小 1000×660。窗口拉小时只有中间的表格压缩，
底部操作卡始终完整可见。

### 屏幕小 / 缩放大的时候会自动让位（v1.12）

程序按"任务栏以外的可用区域"算尺寸（不是整块屏幕），所以 1366×768 的笔记本开 125%、150%
缩放时，窗口也不会顶到任务栏下面。真的挤到放不下时，按三步让位，功能一项不减：

1. 先收紧底部操作卡的留白；
2. 还不够就去掉顶栏副标题和按钮区右侧那行提示（纯说明文字）；
3. 极端情况（如 1366×768 开 150%）再收起表格上方的「作品目录」标题行，把这点高度让给数据行。

实测 12 种屏幕×缩放组合（1024×768 到 3840×2160，100%–200%），表格都至少能显示 2 行以上，
按钮区一行不缺。

## 二、基本用法

1. 双击运行，无需安装、无需 Python 环境。
2. 顶部按 **年份 / 类别 / 奖项 / 资料** 逐级筛选，关键词框可搜学校、作品名、作者。
3. 想挑着下：点每行最左边的方框 ☐ 打勾（变成 ☑），勾完点「下载列表」批量下载；
   也可以 Ctrl/Shift 多选后点「加入下载列表」，或直接点「下载选中」立即下。
4. 默认存到「下载\物理实验竞赛作品」，并自动按「年份\类别·奖项」分文件夹。
5. 双击任意一行，在浏览器打开该作品的官方在线预览（视频直接播放）。

## 二·补、下载列表：先勾选，再分批下载（v1.9 新增）

以前只能"筛选一次、下一次"。清单有一万多条、跨年份对比着挑的时候很难用：
筛 2025 勾几件，换到 2024 再勾几件，前一批勾选就没了。现在有了下载列表。

### 怎么用

1. 点行首方框 ☐ 勾上；再点一下变 ☐ 就取消。勾选跟着作品走，不受筛选、搜索、排序影响，
   可以反复换条件慢慢挑。
2. 点「加入下载列表」按钮，把当前多选的行一次加进去；或点表头的「选」，
   把当前筛选结果整批加入 / 移出。
3. 点「下载列表 (N)」打开列表窗口，核对一遍再下。

### 列表窗口里能做什么

- 看状态：待下载 / 下载中 / 完成 / 已存在 / 失败 / 仅预览（各带颜色）。
- 移除选中、清空列表、清理已完成（只清记录，不动已下载的文件）。
- 「每批 [N] 项」：把大工程切成小批，一批下完自动接下一批，底部实时显示
  「共 N 项　待下载 a　完成 b」。
- 双击某行仍可打开该作品的在线预览。

### 分批下载的两个好处

- **中断不白干**：点「停止」只停当前批次，没下完的仍是「待下载」；关掉程序再开、列表还在
  （存在 `%APPDATA%\AwardsDownloader\queue.json`），接着点「开始下载」就继续，已完成的自动跳过。
- **出错范围小**：一批几十项，哪批出问题一眼能看出来，重试成本低。

### 说明

- 「开始下载」只处理状态为 待下载 / 失败 的项，已完成、已存在的自动跳过。
- 列表里的文档若没勾「文档：预览转PDF」，会被标成「仅预览」并跳过；想连文档一起存成本地 PDF，
  先勾上那个开关再开始。

## 二·补二、连续下载、批量下载为什么不会再出问题（v1.10）

这一版专门把"跑大批量"和"反复下"时容易翻车的地方逐个堵掉了。

### 同一作品的几份资料不会再互相覆盖（重要）

平台给的文件名只到「学校_作品_作者」，同一作品的 PPT、实验报告、视频算出来是同一个名字；
勾了「预览转PDF」后文档又都存成 `.pdf`，于是后下的那份会把先下的那份直接覆盖掉。
全表有 1 659 组、4 066 条的文件名主干会重复（其中 1 488 组、3 278 条连扩展名都相同，不处理就会真正互相覆盖），批量下完一核对发现少了一堆文件，日志里却全是"完成"。

现在按全表预先判重，只给真会撞名的加后缀：

```text
南方科技大学_扭转系数叠加规律探究实验_李海琳_PPT.pdf
南方科技大学_扭转系数叠加规律探究实验_李海琳_实验报告.pdf
```

其余 8 501 条文件名保持原样，之前下好的文件仍然认得出来。

### 断流不再被当成"下载完成"

网络抖动时连接会提前断开，`read()` 返回空而不报错，半个视频就这样被记成"完成"。
现在按 `Content-Length` 逐字节核对，不够就判失败、自动重试（最多 3 次，间隔递增），
并把原因写进日志。

### 分批之间不再有可插入的空档

v1.9 每批结束会先把按钮放开、再等 400 ms 接下一批；这个空档里点「开始下载」就会两套批次叠着跑，
进度和状态互相覆盖。现在整条链跑完才放开按钮，运行中「开始下载」始终是灰的。

### 下载列表里的「停止」终于能点了

v1.9 把它和别的按钮一起禁用了，只能回主窗口停。现在下载中可用。

### 出错不再让界面卡死

界面刷新回调里任何一处异常，过去会让进度条永久停在"下载中"。现在单条事件出错只丢这一条，
下载照跑。

### 其它

- 目标文件正被 PDF 阅读器 / 播放器打开时，自动换个名字保存，不会失败，也不会把原文件写坏。
- 保存路径过长（学校名、作品名都长）时自动收短文件名并加 5 位哈希，下次运行仍算得出同一个名字，
  不影响「跳过已存在」。
- 下载中关窗口会先问一句，确认后等当前分片收尾再退出，不留半截文件。
- 勾了「跳过已存在」再下同一批，第二次是秒过的（不会白跑一遍渲染）。

## 二·补三、换一台电脑也能直接跑（v1.12）

这一版没加功能，专门补"在别人电脑上"的坑。下面每条都对应一类真实机型，不是以防万一的猜测。

### 找不到 Edge 的电脑

以前只在 `C:\Program Files (x86)` 下按固定路径找。系统盘不是 C:、Edge 装在用户目录、
装的是 Beta/Dev 通道、或者只写了注册表，都会误判成"没浏览器"，于是「预览转PDF」被置灰。
现在按 环境变量 → 用户目录 → 注册表 App Paths → PATH 的顺序找，命中即缓存。

### 双开导致"下载莫名失败"

同时开两个窗口会抢同一份下载列表、同一个目标文件、同一个浏览器进程。现在用系统互斥体保证
同一个人只能开一个窗口，第二个会弹一句提示然后退出；进程崩溃也不会留下脏锁（锁随进程释放）。

### APPDATA 被组策略改到只读盘

配置、下载列表、错误日志存在 `%APPDATA%\AwardsDownloader`。这个目录建不了或写不进时，
自动退到 `%LOCALAPPDATA%` → 用户目录 → 临时目录，不再启动即报错。

### OneDrive 接管了「下载」文件夹

默认保存目录改成读注册表里的真实「下载」路径，接 OneDrive 的机器也能存到用户实际在用的
那个下载夹，不会凭空造一个空的 `C:\Users\x\Downloads`。

### 没有微软雅黑的老系统

字体按 微软雅黑 UI → 微软雅黑 → 黑体 → 宋体 顺序挑第一个系统里真有的，挑不到就跟随系统默认字体。
以前写死雅黑，缺字体时中文变方块、列宽还算错。

### 高 DPI / 多显示器

第一次见到 1366×768 开 150% 的机器时，窗口比屏幕还高，底部按钮永远点不到。现在尺寸按
"任务栏以外的可用区域"算，并按内容所需 + 屏幕可用区取小值；放不下时按三步让位（见前文）。

### 点了按钮没反应

打包成无控制台的 exe 后，界面回调里抛异常等于"什么都没发生"。现在统一捕获：
写 `%APPDATA%\AwardsDownloader\error.log`，状态栏显示一行「出错了：…」。遇到怪现象先看这个文件。

### 其它小修

- exe 里的图标终于用上了（打包后图标在临时解包目录，以前按 exe 旁边找）。
- exe 属性里补了产品名、版本 1.12.0.0、说明，个别杀软对"无版本信息的单文件 exe"更敏感，
  补上可降低误报（不是免疫）。
- 窗口标题带上版本号，出问题时一眼能报出是哪个版本。

## 三、2024/2025 文档可以下载了（v1.3 新增）

平台对 2024、2025 两年的文档（PDF/PPT/DOCX）关闭了原始文件下载：资源里 `canDownloadUser`
是空数组，对任何账号都不开放，登录也没用。视频和压缩包不受影响，一直都能下。

但平台的「在线预览」是开放的。本版新增「文档：预览转PDF」功能：程序用浏览器打开预览页，
把页面的每一页读出来，在本地重建成 PDF。

### 怎么用（顺序别搞反）

1. 先勾选底部的 ☑「文档：预览转PDF（慢）」；
2. 再点「下载选中」或「下载当前列表」。

没勾这个框，程序会认为你不需要文档，会提示「有 N 项是文档，只能在线预览」并把这些文档跳过，
这不是功能坏了，是开关没开。v1.4 起，若一次勾了 5 份以上文档，会先弹出耗时预估让你确认。

### 注意事项

- 每份 30 秒～3 分钟，页数越多越久（10 页约 30 秒，65 页约 3 分钟）。程序会自动滚到文档
  最底部把所有页取全，不会只下前几页。
- **串行**：同一时刻只处理一份。并发跑两份会让平台懒加载漏页、产出残页，所以宁可慢也不并行。
- 需系统装有 Edge 或 Chrome（Windows 10/11 默认都有）。若没有，该复选框会自动置灰并在旁边说明原因。
- 产出是「图片版 PDF」：版面、文字、图表、页眉页脚都完整清晰，但文字不可复制、不可检索。
  需要可复制的原始文件时，2020—2023 年的文档仍走原始直链，是真正的矢量 PDF。

### 平台切图有两种，程序按坐标自动判断（无需选择）

- **PDF 类文档**：整页横向切成 3 段长条，自下而上叠 → 纵向拼接。
- **PPT 类文档**：整页竖向切成 3 条窄条，左右并排 → 横向拼接。

两种拼错方向整页内容就会错位，v1.7 已修好。

### 推荐流程

- 少量精品：勾「预览转PDF」，勾进下载列表后直接下；
- 大量收藏：先在下载列表里攒够几十上百项，设每批 20 项慢慢跑；
- 大量浏览：点「导出清单」，生成一个网页，点条目在线看，更省时间。

## 五、文件正确性校验

程序不按 URL 猜扩展名，而是下载后读文件头判断真实类型：

| 文件头 | 判定 |
|---|---|
| `%PDF` | `.pdf` |
| `PK..` | `.docx` / `.pptx` / `.zip` |
| `D0CF11E0..` | `.doc` / `.ppt` |
| `...ftyp` | `.mp4` |
| `Rar!..` | `.rar` |
| `7z..` | `.7z` |

若服务器返回的是网页（HTML/JSON）或空内容，判定为「仅预览」并丢弃临时文件，
绝不写出扩展名与内容不符的文件。上一版「File not in PDF format or corrupted」的问题由此修复。
另外按 `Content-Length` 校验字节数，短了判失败并重试，不会留下半个文件。

## 六、其它

- 「刷新数据」会重新从平台拉取目录树（约 6.8 MB），平台新增作品时用它更新。
- 下载中的临时文件为 `.part`（文件名带任务序号，同批并发不会互相写坏），中断或取消会自动清理；
  程序被杀掉时残留的 `.part` 下次会被覆盖。
- 勾选「跳过已存在」时，同名文件不会重复下载（任意可能的后缀都认得）。
- 日志文件 `_下载日志.txt` 超过 8 MB 会自动滚一份 `.1`。

## 六·补、出问题了怎么查

程序不会只在界面上丢一行"失败"就完事，失败详情都会落到「保存目录\_下载日志.txt」，
里面有完整的异常堆栈；提 issue 时请把它和 `--diag` 输出一起附上。

另有两个自检命令（在 exe 所在目录打开命令行执行）：

### `AwardsDownloader.exe --diag`

检查环境：版本、能否找到 Edge、能不能真的把浏览器拉起来。结果写入 exe 旁边的 `diag.txt`
（那里不可写就写临时目录）。正常应看到类似：

```text
version=v1.12
frozen=True
app_dir 可写=True
字体=Microsoft YaHei UI
screen=1920x1080  dpi=96
内置清单=... 存在=True
preview_pdf available=(True, '')
cdp launch OK  0.5s
```

v1.12 起还会打印系统版本、默认保存目录、内置清单是否存在，贴在反馈里就能定位大部分
"我这里不行"。

### `AwardsDownloader.exe --testdownload <资源ID>`

完整跑一遍「下载一份 2024 文档」的流程（约 25 秒），结果写入 `testdownload.txt`。成功应看到类似：

```text
自检_自检文档_实验报告.pdf  6090553 bytes  head=b'%PDF-1.4'
```

资源 ID 可在列表里查（2024 光偏振实验是 `67f4c272d13ab03f90569254`）。

若界面提示「（不可用：未找到 Edge/Chrome 浏览器）」，先跑 `--diag` 确认。

## 七、技术说明

- 全部功能只用 Python 标准库，exe 约 12 MB，不需要装任何东西。
  （v1.4 及以前用 playwright，exe 有 49 MB，v1.5 已彻底去掉。）
- 单文件 exe 首次运行会自解压到临时目录，启动约 1–2 秒；若临时目录被杀软实时扫描，
  首次启动可能慢到 5 秒以上，属正常现象。
- 「预览转PDF」直接驱动系统自带的 Edge/Chrome：程序自己实现浏览器的调试协议
  （DevTools Protocol），在跨域渲染 iframe 里读页面结构、抓分页图、必要时截图。
  浏览器启动约 0.4 秒，不占用你正在用的浏览器窗口。
- PDF 合成与 PNG 解码全部手写实现（不引入 Pillow）：解 PNG 的 IDAT → 还原滤波 → 去 alpha →
  压缩后嵌入 PDF 的 `/XObject /Image`，手写 xref 表。
