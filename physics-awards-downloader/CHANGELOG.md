# 更新日志

本项目遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 的记录方式。
版本号按开发顺序递增（v1.0 → v1.12），未严格遵循语义化版本；每个版本都可能同时包含功能、
修复与兼容性改动。

  整理开发记录为可公开阅读的版本。

## [1.12] - 2026-10-25

### Changed

- 「换一台电脑也能直接跑」兼容性收尾：浏览器发现改为环境变量 → 用户目录 → 注册表 → `PATH`
  分层查找；配置目录在 `%APPDATA%` 不可写时逐级回退；默认保存目录读取系统真实「下载」路径；
  中文字体改为运行时探测并回退；窗口尺寸按任务栏以外的可用区计算，小屏按三级让位。
- 单实例：命名互斥体限制同时只开一个窗口，避免抢下载列表、目标文件与浏览器 profile。
- 界面回调异常统一写入 `error.log`，无控制台 exe 不再静默失败。
- 打包：exe 补版本资源（产品名 / 1.12.0.0 / 说明），降低杀软误报；图标改为从 `sys._MEIPASS` 读取。

### Fixed

- 修复系统盘非 C:、Edge 装在用户目录或只写注册表时「预览转PDF」被误置灰的问题。
- 修复高 DPI / 小屏下窗口高于屏幕、底部按钮点不到的问题。

## [1.11] - 2026-10-25

### Changed

- 界面重做：浅蓝白圆角卡片风格，新增自绘控件库 `src/ui_kit.py`（圆角卡片、药丸按钮、
  胶囊开关、胶囊进度条、圆角输入框），全部用 Canvas 绘制、仅依赖标准库。
- 配色收敛为淡蓝主色 + 冷灰中性色，红绿只用于失败 / 完成状态。
- 表格布局改为可压缩，窗口变小时只压缩目录表，底部操作卡始终完整可见。

### Fixed

- 修复自绘卡片高度计算失败导致筛选栏与底部操作区消失的问题。
- 修复 Treeview 直接 pack 时挤掉底部操作卡的问题。

## [1.10] - 2026-10-25

### Fixed

- 同一作品的多份资料文件名相同导致互相覆盖（全表 1 659 组 / 4 066 行主干同名，其中 1 488 组 / 3 278 行连扩展名都相同）：改为按全量目录
  预先判重，只给真会撞名的行补资料类型后缀，并保证多次计算结果一致。
- 分批下载之间的 400 ms 空档可被再次点击「开始下载」插入，导致两套批次叠加：
  改为每条链独立事件队列 + 运行号，整条链跑完才放开按钮。
- 下载列表窗口的「停止」按钮在下载中被误禁用。
- 主窗口「停止」只停当前批、仍会自动接下一批的问题。
- 连接提前断开时半截文件被记为「完成」：改为按 `Content-Length` 校验并重试（最多 3 次）。
- 同批任务的 `.part` 临时文件可能同名互写；落盘被占用时改为换名保存。
- 事件泵缺少异常保护可能永久停在「下载中」；补齐 `sniff_ext` 的 RAR / 7z / GIF / WebP 判定、
  「跳过已存在」的后缀表，并处理超长路径（232 字符预算 + 5 位哈希）。

## [1.9] - 2026-10-25

### Added

- 下载列表：跨筛选勾选累积，独立窗口查看状态、移除 / 清空 / 清理已完成。
- 分批下载：每批 N 项，一批结束自动接下一批；停止只停当前批，未完成项保留。
- `queue.json` 持久化，重开程序后勾选与状态仍在（「下载中」自动回落到「待下载」）。

### Changed

- 主窗口「下载选中 / 下载当前列表」与下载列表共用同一条 `launch()` 下发链路。
- 下载表格新增勾选列，勾选状态用业务键标识，不受筛选排序影响。

## [1.8] - 2026-10-25

### Fixed

- 长文档只取到前 10 页：平台预览是虚拟列表，原代码把空壳元素当滚动容器，滚动从未生效。
  改为取"可滚动高度最大"的元素、使用内容坐标、滚到底采集，并两轮补齐缺口。
- 修复横放页、A3 插图等混排导致的页数误判（页距改用中位数推算）。

## [1.7] - 2026-10-25

### Fixed

- PPT 型文档内容错位：平台对 PPT 是竖切 3 条，原代码一律纵向拼接。改为按切片在页内的
  x/y 跨度判断方向，PDF 型纵向拼、PPT 型横向拼。
- 首屏抓到的残缺切片被锁死：改为"只允许变多"，并增加页内切片补齐。

## [1.6] - 2026-10-25

### Fixed

- 「浏览器启动后立即退出」误判：Chromium 在 Windows 上可能由另一个进程接管、启动器先退出，
  原代码用子进程存活判定，把正常浏览器误杀。改为以 `DevToolsActivePort` 出现且端口可访问为准。
- 启动失败路径未清理临时 profile；增加失败重试与降级（无头 → 无沙箱 → 离屏窗口）、
  可靠关闭进程树、启动时清扫残留 profile。

## [1.5] - 2026-10-25

### Changed

- 去掉 playwright，改为自写 CDP 客户端 `src/cdp.py`：WebSocket 手写、`--remote-debugging-port=0`、
  OOPIF 用 `Target.attachToTarget`、`Runtime.evaluate` 使用自执行形式。
- exe 体积 49.3 MB → 约 12 MB；单份文档转换 43~55 秒 → 约 22 秒。

### Fixed

- 优化 PNG 解码与纵向拼接（步长切片、大整数加法、整块复制），优化前后产物逐字节一致。
- 回退"2 路并发浏览器"方案：并发会导致懒加载漏页、产出残页。

## [1.4] - 2026-10-25
